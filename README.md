How to use.

Step 1.) Go to site.

Step 2.) Click the company logo in the top left corner twice.

Step 3.) Scroll down to the bottom of the page and click sign in. There is no need to actually type in anything. 

Step 4.) Have fun! To find a game just search it by name in the search bar. Despite the names not being labeled on the site, in the code they have hidden search tags that allow them to be searched by name or number.
